# 管线智联 · 本地演示（localhost）

本项目由三部分组成：

| 部分 | 路径 | 说明 |
| --- | --- | --- |
| 演示数据服务 | `demo/server.mjs` | 零依赖 Node HTTP 服务，在 **8080** 提供 `/api/v1` 演示接口（含 106 家会员、35 条政策、24 条招标与完整生态数据） |
| 演示数据 | `demo/data/*.json` | 106 家会员、35 条政策标准、24 条招标公告（7–8 月） |
| Web 管理端 | `apps/web` | 真实 Vue 3 界面（开发模式 + 本地身份） |

> 说明：本机没有 Java/Docker 时用这套跑演示；正式部署走仓库原有 Java 后端
> （`apps/server`，招标等新功能代码已按模块规范写入，见仓库根 README）。

## 一键启动

```bash
./demo/start.sh
```

脚本会依次启动演示数据服务（8080）和 Vite（默认 5173；被占用时自动换端口，
**以 Vite 打印的地址为准**），然后打开浏览器。

## 手动启动（两个终端）

```bash
# 终端 1：演示数据服务
node demo/server.mjs            # 或 PORT=8081 node demo/server.mjs

# 终端 2：前端
cd apps/web
npm install                     # 首次
npm run dev                     # Vite 会打印访问地址
```

打开 Vite 打印的地址（如 `http://localhost:5173/`）。

## 登录方式（演示身份）

页面提供 5 种登录身份，登录后即可按角色看到对应界面：

| 身份 | 角色 | 适合演示 |
| --- | --- | --- |
| 协会管理员（张全超） | 协会侧 | 协会工作台、会员企业、政策标准、招标信息、生态匹配等完整功能 |
| 系统管理员 | 协会侧 | 同协会侧，另含全平台上下文切换 |
| 协会运营人员（徐明） | 协会侧 | 运营工作 |
| 企业管理员（王志远 · 京城管网） | 企业侧 | 企业工作台、"与我相关"招标、政策提醒、商机 |
| 企业业务人员（李楠） | 企业侧 | 企业视角只读协作 |

## 演示建议路径

1. **协会管理员登录** → 协会工作台：看 106 家会员、会员区域分布（昌平区/回天居首）、行业场景、最新动态、待推进协作。
2. **会员企业**：全量 106 家名单与画像，支持搜索、筛选、导入模板下载、批量预检。
3. **政策标准**：35 条真实法规（安全生产法、城镇燃气管理条例、北京市地下管线管理办法等），企业影响分析、订阅与带出处问答。
4. **招标信息**（新增）：24 条 7–8 月真实风格招标（回龙观供热改造、天通苑排水、回天管线探测等）；点"推送"→ 选"推送给全部会员"或"定向选择"→ 完成推送；"推送记录"可查明细。
5. **切换企业管理员登录** → 企业工作台顶部出现"为您匹配的招标机会"；招标信息页默认"与我相关"（带匹配度与"协会已推送"标记），右上角铃铛有招标推送通知。
6. 其余页面：产品与需求 / 生态匹配（96 分可解释推荐）/ 协作事项 / 资料附件 / 友好协会均可演示。

## 新增功能与对应文件

| 功能 | 演示服务 | 前端 | Java 后端（正式部署用） |
| --- | --- | --- | --- |
| 招标列表/收录/批量 | `demo/server.mjs`（`/tenders`） | `apps/web/src/views/TendersView.vue`、`navigation.ts`、`router/index.ts`、`platform-api.ts` | `apps/server/tender/` 模块 |
| 协会推送招标 + 记录 | `/tenders/{id}/push`、`/pushes` | `TendersView.vue` 推送弹窗 | `TenderService` / `TenderPush*` |
| 企业"与我相关" | `/tenders/mine` | `TendersView.vue` 模式切换、企业工作台"招标机会"面板 | `TenderService.mine()` |
| 会员分布可视化 | `/members/distribution` | 协会工作台"会员区域分布与能力资产" | `MemberService.distribution()` + `GET /members/distribution` |

数据说明：106 家会员为企业名虚构的**待替换数据**（理事长已确认用会员目录 + AI 生成 Excel
导入，导入闭环在"会员企业 → 导入企业资料"），招标记录为 7–8 月**真实风格**公告，正式演示前
建议用采招网账号抓取替换真实公告（`/tenders/batch` 已支持批量）。

## 备注

- 所有演示数据仅存于内存/JSON，不写库、不落盘、无外部调用。
- 演示服务读取 `demo/data/*.json`；若某文件缺失会自动退化为内置最小种子。
- 生产接口契约以 `apps/server` 为准，本服务仅用于本地演示。
