# 企业资料草稿、审核与公开发布

日期：2026-09-05。状态：本地实现并测试，**未推送、部署或操作生产数据**。
承接 `visitor-enterprise-access-policy.md`；取代上一阶段“保存直接更新主档并转待审核”的做法。

## 操作闭环

1. 企业负责人从“我的企业”维护普通业务资料，点击“保存草稿”。保存不改内部正式资料、企业可用状态或游客版本。
2. 点击“提交协会审核”冻结服务器上的草稿。此时不能继续修改该版本；并发版本不一致时返回 412，不覆盖输入。
3. 协会管理员或选择了对应协会范围的系统管理员，在“会员企业 → 查看资料待审核队列”打开企业。页面展示当前正式资料与冻结草稿的字段差异。
4. 审核必须填写说明。退回后，负责人看到原因，修改保存后重新提交；上次退回原因在修改、重新提交期间保留。所有编辑人和提交人都不能审核该稿，即使后来换成管理员角色。
5. 审核通过仅更新内部正式资料。企业可用状态沿用原状态，不因普通草稿变成待审核，也不代替新企业入库/会员资格审核。原本待完善或待入库的企业仍须走原有管理核验。
6. 企业负责人核对“游客视角预览”，主动勾选并确认**这个已审核版本**允许公开。联系人、电话、邮箱、详细地址、信用代码、合作需求不在公开字段白名单中。自由文本仍须人工检查，系统没有承诺自动识别全部敏感内容。
7. 独立管理员再次核对预览并“发布已审核版本”。只有此动作才更新游客快照；批准、导入、旧 `PUBLIC` 和 `ACTIVE` 都不会自动发布。
8. 负责人或审核管理员填写原因后可立即撤回公开展示，同时清除旧授权。未保存草稿不阻止紧急撤回。重新发布需重新授权。

新草稿、提交、退回，甚至新版本内部审核通过，都不会覆盖上一份游客快照。只有对应审核版本重新授权并发布后才切换。游客页面 `/public` 只请求独立公开接口，不初始化 OIDC、不发送登录令牌或系统代管上下文。

## 后端与并发边界

- 新增 `V26__enterprise_profile_workflow.sql`，不回填或自动公开任何既有企业。
- 一张版本化工作流表持有当前草稿、最新内部审核快照、版本授权和独立公开快照。冻结提交、审核、授权、发布、撤回的完整状态证据进入受权限控制的审计记录。页面显示当前/上次审核反馈，不是完整历史版本浏览器。
- 所有写操作要求强 `If-Match`；保存另带客户端看到的正式 `baseVersion`。正式资料有并发修改时，提交/批准/授权/发布拒绝覆盖旧版本；退回仍可执行，方便负责人重新核对。
- 写事务按协会 → 企业 → 工作流顺序加锁，正式主档更新、工作流更新和审计同事务提交。测试覆盖并发审核只有一次成功、审计失败整体回滚。
- 主档和工作流详情在可重复读事务中读取，避免审核页面拼接出两次并发提交前后的不同版本。
- 企业负责人仅本企业；普通企业成员不能看私有草稿或编辑；协会运营能协助编辑/提交、不能终审/发布；跨协会或无明确协会范围的系统管理员不能处理草稿。
- 原 `PUT /my-enterprise` 和企业负责人/运营对旧 `PUT /members/{id}`（含 `/enterprises` 别名）的直接主档写入返回 `PROFILE_DRAFT_REQUIRED`，不能绕过草稿闭环。
- 保留既有受审计的管理员主档核验接口及入库/停用/恢复操作，UI 折叠到“管理员主档核验”。这是受信任管理员的维护路径，不会更新公开快照；不是这次新增的身份更正申请审批功能。
- 公开目录在 SQL 层仅对已发布快照的名称/类别筛选、排序、分页；不使用内部地址、联系方式、草稿字段或内部总数。每页 20 条。
- 公开 DTO 只有 `id/name/category/introduction/capabilities/products/services/applicationScenarios/publicationId/publishedAt`。公开时间不是内部更新时间；显示“资料已审核”，不暗示官方资质认证。
- 公开查询同时检查企业 ACTIVE、未删除、协会 ACTIVE。PostgreSQL 生命周期触发器在企业状态/删除/归属或协会状态变化时立即下架、增加授权世代和流程版本；恢复不自动重新发布，也不能复用旧世代授权。
- API 响应与公开客户端均 `no-store`，没有新增公开缓存、搜索索引、匿名 Chat 或附件权限。已经被外部访问者看到、复制或下载的历史公开内容无法远程追回；已打开页面也不会主动抹除用户已经看到的内容。

## 接口

| 路径 | 用途 |
| --- | --- |
| `GET /api/v1/enterprise-profiles/{id}` | 授权负责人/协会管理人员读取主档、草稿、反馈与发布状态 |
| `PUT .../{id}/draft` | `{content,baseVersion}`，保存独立草稿 |
| `POST .../{id}/submit` | 冻结并提交当前草稿 |
| `POST .../{id}/review` | `{approve,note}`，独立审核并内部生效或退回 |
| `POST .../{id}/consent` | `{confirmed:true}`，仅本企业负责人确认审核版本公开授权 |
| `POST .../{id}/publish` | 审核管理员发布已经授权的审核版本 |
| `POST .../{id}/withdraw` | `{note}`，负责人或审核管理员撤回展示及授权 |
| `GET /api/v1/enterprise-profile-reviews?page=0` | 当前协会/代管企业范围内的待审核队列 |
| `GET /api/v1/public/enterprises?q=&page=0` | 匿名公开快照分页；不返回内部总数 |
| `GET /api/v1/public/enterprises/{id}` | 匿名公开详情；未发布、不存在或不可用统一 404 |

仅最后两个精确 GET 路径放行匿名；内部接口及其他 HTTP 方法不放行。
